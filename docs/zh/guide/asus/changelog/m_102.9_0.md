#### Asuswrt-Merlin 3006.102.9 更新日志

  - 新增：已将所有设备迁移至 OpenSSL 3.5（GT-BE19000AI 除外，该设备原本已使用此版本）。
         对于链接到 OpenSSL 1.1.1 的闭源组件，开发了兼容层（shim），使其伪装为 OpenSSL 1.1.1 库，并将调用重定向至实际的 3.5.x 库。同时，为 RT-BE58_Go 的 Trend Micro HNS 引擎实现了类似的 1.0.0 兼容层。（RSDNTWK）

  - 新增：已实现硬件加速的 AQM QoS，使用 Broadcom 的流量管理器。Wi-Fi 6 设备将使用 WRED 算法，而 Wi-Fi 7 使用 PI2。
         此功能不兼容 BCM676x 设备，例如 RT-BE92U 或 RT-BE58_Go。

         AQM 通过改进队列管理帮助减少缓冲区膨胀（bufferbloat）。这仅影响上传方向，因为华硕已在下行方向使用另一套 Broadcom 引擎应用队列管理。

         建议将上传速度设置为实际上传速度的约 95%。

         仅支持 DHCP/静态模式（因此不支持 PPPoE）。

  - 新增：无线日志现将报告中继器（Repeater）、媒体桥接（Media Bridge）和 WISP 上游链路的信息
  - 新增：Tor 支持 IPv6。此前，任何 IPv6 流量都会绕过代理泄漏。（Claude）
  - 更新：amtm 至 7.0。（decoderman）
  - 更新：tor 至 0.4.9.11。
  - 更新：OpenSSL 3.5 至 3.5.8。
  - 更新：OpenVPN 2.7.7。
  - 更新：时区数据（zoneinfo）至 2026c。
  - 变更：内核回移植，将基于 B53 的 CPU 标记为不易受 Spectre V2 和 Meltdown 攻击。
             这告知内核跳过软件缓解措施，从而避免其相关的性能损失。（leonpano2006）
  - 变更：对 OpenVPN 服务器和 Tor 页面的调整。使用新的 CSS 单选开关替代旧的 switcherplugin。
  - 变更：停止在固件升级后强制（重新）启用 FTP TLS。
  - 修复：在 WISP 模式下无线日志无法工作的问题。
  - 修复：在中继器和媒体桥接模式下无线日志的问题。
  - 修复：速度测试中缺少接口选择的问题（GT-BE19000AI）
  - 修复：AdaptiveQoS 带宽监视器显示错误的流量速率（来自华硕的补丁）
